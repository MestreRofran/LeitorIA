# LeitorIA

Leitor de textos/PDF com voz do dispositivo e suporte experimental a voz natural local.

## Publicação
Este leitor usa as vozes do dispositivo local para fazer a leitura.
Você pode escolher a voz que preferir nas configurações.
A aolicação é simples e direta: Cole e ouça.
Você também pode gerar um arquivo de audio, se preferir.
